■ゲーム紹介

ある日、どうぶつたちが暮らす平和な森に
黒い隕石が落下した。

森は暗黒世界へ変わり、
どうぶつたちは黒い姿・赤い目になってしまった。

主人公の四足歩行トカゲが
仲間たちを救うため冒険へ出発する。

ラスボス「暗黒の虎」を倒し、
森に平和を取り戻そう！
